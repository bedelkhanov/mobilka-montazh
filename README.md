# Мобилка монтаж

Скил для Claude: монтаж вертикального рилса, снятого на телефон, в стиле «одно слово на экране + анимированные вставки на белом фоне с вырезанной головой». Русский и казахский.

## Установка

Скажи Claude (с телефона или компьютера): «установи скил из github.com/bedelkhanov/mobilka-montazh» — или скачай архив репозитория и загрузи его в Claude как скил (Settings → Capabilities → Skills).

## Как пользоваться

Пришли видео в чат и напиши «мобилка монтаж». Claude сам:

1. приведёт видео к 1080×1920, распознает речь (faster-whisper large-v3);
2. вырежет паузы, дубли и оговорки — голос не обрабатывается;
3. разобьёт речь на карточки субтитров, отметит акцентные слова;
4. подберёт вставки по смыслу (чеклист, чат, заявки, график, воронка, цена, A/B, контент-план, карта, папка, карточки, таймлайн, маркер, заголовок);
5. соберёт ролик: Chrome рисует слой текста и анимаций, Python — белый фон, рамку и вырезанную голову;
6. расставит звуковые эффекты из `sfx/` (птык, тап айфона, тики) на всё, что появляется на экране; громкость подстраивается под голос, сам голос не обрабатывается.

## Состав

- `SKILL.md` — инструкция для Claude
- `mm.py` — движок (setup, prep, transcribe, cut, analyze, plan, render, sheet, sfx)
- `overlay.html` — субтитры и 17 шаблонов вставок (тот же дизайн, что в Claude Design)
- `vstavki.md` — каталог вставок и формат `plan.json`
- `sfx/` — звуковые эффекты Асланбека и `sfx.json` (куда какой звук ставить)

Шрифты (Inter Display, Noto Serif Display — SIL OFL 1.1) и модель MediaPipe для вырезания головы (Apache 2.0) скачиваются командой `python3 mm.py setup`.
