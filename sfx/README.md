Звуковые эффекты Асланбека. Движок ставит их сам (`"sfx": "auto"` в plan.json):

- `click.wav` — птык: вход вставки, каждый новый элемент, акцентное слово
- `iphone_tab.mp3` — тап айфона: сообщения, чат, уведомления
- `ticks.wav` — тики: счётчики, графики, кольцо, календарь

Новый звук: положи файл сюда и допиши его в `sfx.json` (onset, rel, use).
